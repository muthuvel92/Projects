# Data Cleaning Techniques

## Files:
- **01_remove_duplicates.py** - Remove duplicate rows
- **02_drop_columns.py** - Drop unnecessary columns
- **03_clean_strings.py** - Strip and clean text
- **04_clean_phone_numbers.py** - Standardize phone formats
- **05_split_columns.py** - Split columns into multiple columns
- **06_standardize_values.py** - Standardize Yes/No values
- **07_handle_missing_values.py** - Handle NaN and empty values
