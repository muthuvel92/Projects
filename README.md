## Loan Approval Prediction (An end-to-end Machine Learning classification project to predict loan approval using applicant and loan-related features.

The project covers **EDA, data cleaning, KNN imputation, categorical encoding, feature scaling, class-imbalance analysis, model comparison, cross-validation, and hyperparameter tuning using GridSearchCV**.

Multiple models including **Logistic Regression, Decision Tree, Random Forest, XGBoost, and Gradient Boosting** were evaluated using Accuracy, Precision, Recall, F1-score, ROC-AUC, and Confusion Matrix.

The project focuses not only on model performance, but also on **model generalization, preprocessing decisions, class-imbalance trade-offs, and business-oriented model selection**.

**Tech Stack:** Python • Pandas • NumPy • Scikit-learn • XGBoost • Matplotlib • Seaborn)
